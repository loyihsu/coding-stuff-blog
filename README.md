# Coding Stuff

[Coding Stuff](https://codes.loyi.dev/) is Loyi Hsu's personal technical blog, covering Swift, iOS, and other development topics.

This repository contains the generated static HTML, CSS, and JavaScript published by the site. Jekyll source files, configuration, and build scripts are not included.

- `index.html`, `page2/`: home page and pagination
- `posts/`: article pages
- `archive/`, `tags/`, `about.html`: article indexes and site information
- `assets/css/main.css`, `assets/js/post.js`: custom site theme and interactions

To preview the generated site locally, run this from the repository root:

```sh
python3 -m http.server
```
