lofy

lofy, as in lo-fi, is a minimal, typographic Jekyll theme, and this page is a sneak peek at it. It follows one rule: everything on the page should either help you read or get out of the way. Everything below is live, so try it as you go. This site uses lofy 0.1.0.

Reading

  • Type does the work. Headings and body text are set in Newsreader, the interface in Inter, and code in JetBrains Mono.
  • Reader settings. Open customise at the top of the page to pick an auto, light or dark theme. On a desktop, focus reading hides everything but this page.
  • On this page. The headings here make up the table of contents: beside the text on a wide screen, or in a collapsible block above it. The section you are reading is marked as you scroll.
  • Topics. Curated reading lists with a title, a description and an optional cover, listed in the sidebar above the tags, and as an outlined pill before each post’s tags.
  • Heading anchors. Point at a heading to reveal a # in the margin that links straight to it.
  • Link previews. Point at a link to a post, such as the latest one, to see its date, title and summary.

Images

An image on its own line gets its alt text as a caption. Click it to open it larger, click again to zoom in and drag around, and click the dark background to put it back.

Code

A code block can carry a label and highlight the lines that matter:

func readingMinutes(for text: String) -> Int {
    let words = text.split(whereSeparator: \.isWhitespace).count
    return words / 220 + 1
}

A change shows the old and new lines together. The copy button leaves the removed lines out:

func readingMinutes(for text: String) -> Int {
    let words = text.split(separator: " ").count
    let words = text.split(whereSeparator: \.isWhitespace).count
    return words / 220 + 1
}

Terminal commands get a terminal frame, and copying them leaves out the $ prompts:

$ swift build
$ swift test

Program output has its own frame and no copy button, and joins the code above it into one card:

print(readingMinutes(for: "Help you read or get out of the way."))

1

Errors tint the whole block:

let minutes = readingMinutes(for: nil)

error: 'nil' is not compatible with expected argument type 'String'

A message mentioned on its own gets a small diagnostic card:

Cannot convert value of type 'Int' to specified type 'String'

Initialization of immutable value 'minutes' was never used; consider replacing with assignment to '_' or removing it
